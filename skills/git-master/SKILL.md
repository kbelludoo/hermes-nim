# Git Master Skill

When this skill is activated:
1. Prefer clean, atomic git commits with clear conventional commit messages (e.g. `feat:`, `fix:`, `refactor:`, `test:`).
2. Always inspect `git status` and `git diff` before committing.
3. Handle rebases safely: avoid destructive squashes of other people's commits without permission.
4. For diagnosing regressions, recommend or run `git bisect`.
5. Maintain linear history when possible.
