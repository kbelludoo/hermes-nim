Engineered for Performance & Reach

Zero external runtimes required. One standalone binary that executes anywhere from a $3 VPS or Raspberry Pi to local workstations.

🧠

Native ReAct Loop

Full reasoning, decision-making, and tool dispatching loop written in 100% pure Nim with deterministic cycle-collecting ORC memory management.

🌐

Autonomous Web Browser

Directly integrated with AI-Rust-Browser via Model Context Protocol (MCP). Navigates, snapshots in Markdown (#ref:N), clicks, and fills forms at ~6.5 MiB RAM.

⚡

Native Coding Tools

Includes atomic file operations (read_file, write_file, edit_file), recursive search, and native terminal shell execution with output budgeting.

💾

Persistent Cognitive Memory

Preserves facts, user preferences, and cross-session knowledge in persistent storage without overhead or slow databases.

🔌

Universal LLM Client

Native high-performance HTTP/HTTPS client compatible with OpenRouter, OpenAI, DeepSeek, Google Gemini, Ollama, and Groq with exponential backoff.

🛡️

Zero Resident Python

Python is never kept alive in the background. If Python code execution is delegated, a transient standard-library micro-worker runs and exits in milliseconds.

Quickstart

Compile from source in seconds with Nim 2.0+ and GCC.

# 1. Clone repository git clone https://github.com/kbelludoo/hermes-nim.git cd hermes-nim # 2. Build native release binary (Windows) .\build.bat # Or Linux / macOS: ./build.sh # 3. Configure API key (.env) echo OPENROUTER_API_KEY=your_key_here > .env echo HERMES_MODEL=anthropic/claude-3.5-sonnet >> .env # 4. Launch interactive CLI REPL .\bin\hermes.exe # 5. One-shot command mode .\bin\hermes.exe -p "Read package.json and summarize the project"
